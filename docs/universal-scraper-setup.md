# Универсальный парсер

Код универсального парсера сохранён из ветки `univac-merge`. Его расписание по умолчанию отключено (`UNIVERSAL_SCRAPER_SCHEDULER_ENABLED=false`).

Для отдельного окружения предусмотрен дополнительный Compose-файл:

```sh
docker compose -f docker-compose.yml -f docker-compose.universal.yml config
```

Это окружение меняет настройки базы данных и очередей приложения и добавляет PostgreSQL, Redis, Ollama и обработчик очереди. Перед запуском необходимо отдельно настроить пароли и переменные окружения, проверить миграции и совместимость с существующими данными. Не подключайте его к действующему окружению без отдельной проверки.

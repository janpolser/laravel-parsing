# Возобновление сбора HireHi

Команда `hirehi:parse-vacancies` сохраняет список вакансий после завершения
сбора всех страниц, а затем сохраняет каждую обработанную карточку в
`storage/app/private/hirehi-checkpoints/`. После прерывания повторный запуск
с теми же параметрами категории, поиска и страниц продолжает этот список.
Если сбор списка ещё не завершился, его получение начинается заново.

Для карточек, которые не удалось получить, по умолчанию выполняются два
дополнительных прохода. Количество настраивается через
`--detail-retry-passes`; `--max-retries` ограничивает повторы каждого запроса.
По умолчанию интервал между запросами составляет случайные 4–10 секунд.
После проходов недоступные карточки пропускаются, а их ID и причины
сохраняются в файле `report-*.json` в каталоге состояния. Следующий сбор после
успешного завершения начинает новый список, сохраняя предыдущие отчёты.

Ответ 403 останавливает команду и включает существующую защиту HireHi;
возобновление возможно только после разрешения этой защиты. Изменение кода не
влияет на уже запущенные процессы.

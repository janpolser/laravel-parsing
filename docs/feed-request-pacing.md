# Интервалы запросов фидов

Для команд фидов Магнит, Яндекс, Пятёрочка, Перекрёсток, Красное&Белое, РЖД, Wildberries, Ozon, Лента, Монетка, Дикси, ВкусВилл, Купер и Oez ограничитель выдерживает случайный интервал 3–6 секунд между началом HTTP-запросов. Ограничение действует также на повторы и перенаправления.

Время последнего запроса хранится в `storage/app/private/feed-request-pacing` и защищено файловой блокировкой, поэтому параллельные команды одного источника используют общую очередь. Команды Wildberries объединены в одну группу, а Пятёрочка и Перекрёсток — в другую, поскольку они используют один сервер API. Запросы Красного&Белого выполняются последовательно.

Госслужба и HireHi сохраняют собственные интервалы и защитные механизмы. На работу web-приложения, очередей универсального парсера и вызовов LLM ограничитель не распространяется. Ограничиваются HTTP-запросы через Laravel HTTP client команд фидов; автоматические запросы ресурсов страницы внутри браузера Playwright не учитываются.

По умолчанию ограничитель включён в обычном окружении и выключен для тестов. Изменение применяется к новым процессам команд; уже запущенные процессы продолжают работу с ранее загруженным кодом. Повторы с увеличенным backoff и медленные ответы могут увеличить фактический интервал сверх шести секунд.

# Расписание фидов

Все запуски выполняются раз в неделю, время московское.

| День | Время | Фиды |
|---|---|---|
| Понедельник | 07:00 | Пятёрочка, Перекрёсток |
| Вторник | 07:00 | Магнит, ДИКСИ |
| Среда | 04:00 | HireHi |
| Среда | 07:00 | Яндекс |
| Четверг | 07:00 | РЖД, Лента |
| Пятница | 07:00 | Госслужба, Монетка, Монетка-пекарни |
| Суббота | 07:00 | Wildberries, Ozon |
| Воскресенье | 07:00 | Красное&Белое, ВкусВилл, ВкусВилл-все вакансии, Купер |

Публикация архива запускается после успешного сбора соответствующего фида.
Для Wildberries сначала выполняются основной сбор и четыре дополнительные
команды, затем создаётся общий архив. При ошибке любой из них архив не
обновляется. Если включён внешний runner Госслужбы, он использует собственный
crontab, а внутреннее расписание Госслужбы отключается.

При активной защите HireHi или Госслужбы запланированный запуск завершается без
запросов согласно правилам соответствующего парсера. Продолжительные сборы
могут выходить за пределы указанного дня.

# Небольшие изменения каталога

Для источников, которые сообщают количество вакансий, допустимо расхождение
до 10 уникальных вакансий между счётчиком и собранным списком. Это учитывает
добавления и удаления во время обхода; цифра счётчика не считается точным
снимком. Большое расхождение, пустой каталог, HTTP-ошибки и некорректные
страницы по-прежнему останавливают публикацию. Повторы ID удаляются; страница,
целиком повторяющая уже полученные записи, считается ошибкой там, где
проверяется уникальность страниц.

Госслужба собирает список одним проходом. При HTTP 404/410 отдельных карточек
можно пропустить до 10 удалённых вакансий; прочие ошибки карточек останавливают
сбор. Красное&Белое допускает до 10 расхождений суммарно по городам и не делает
повторный запрос справочника для проверки изменений. Некоторые фиды не имеют
счётчика или уже допускают пропуски и не требуют такой проверки.

Полученный список не является точным снимком на момент окончания сбора: при
нестабильной постраничной выдаче отдельные добавленные или удалённые вакансии
могут попасть в следующий запуск.

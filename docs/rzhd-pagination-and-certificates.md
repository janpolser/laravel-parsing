# РЖД: постраничный сбор и получение российских сертификатов

## Постраничный сбор

`php artisan rzhd:collect-vacancies` запрашивает каталог по 500 записей,
начиная с первой страницы, и обходит все страницы из `meta.pages`.
Перед загрузкой деталей и записью XML проверяются:

- номер каждой страницы и корректность её ответа;
- неизменность `meta.count` и `meta.pages` во время обхода;
- положительные уникальные ID вакансий;
- совпадение итогового количества записей с `meta.count`.

HTTP-ошибка, пустая страница, дубликат ID или неполный список завершают
команду с ошибкой до записи XML. Предыдущий XML сохраняется.
Если каталог изменился во время обхода, сбор нужно повторить.

Проверка полноты относится к списку из API. Загрузка деталей и существующие
правила пропуска записей XML-форматтером этим изменением не меняются.
Текущая настройка TLS также сохраняется.

Локальная проверка без сетевых запросов:

```bash
php vendor/bin/pest tests/Unit/RzhdCollectionTest.php
```

## Как получить сертификаты НУЦ Минцифры

1. Откройте [официальную страницу Госуслуг](https://www.gosuslugi.ru/crt)
   в браузере и выберите Linux.
2. Скачайте корневой **Russian Trusted Root CA** и выпускающий
   **Russian Trusted Sub CA**. Если получен архив, распакуйте его.
3. Сохраните исходные файлы. Для Debian-контейнера нужны PEM-файлы;
   примеры имён — `russian_trusted_root_ca_pem.crt` и
   `russian_trusted_sub_ca_pem.crt`. Имена в загрузке могут отличаться.
4. Проверьте владельца, издателя, срок действия и SHA-256:

```bash
openssl x509 -in russian_trusted_root_ca_pem.crt -noout \
  -subject -issuer -dates -sha256 -fingerprint
openssl x509 -in russian_trusted_sub_ca_pem.crt -noout \
  -subject -issuer -dates -sha256 -fingerprint
```

Если файл `.cer` имеет формат DER, сначала преобразуйте его, подставив
фактическое имя файла:

```bash
openssl x509 -inform DER -in russian_trusted_root_ca.cer \
  -out russian_trusted_root_ca_pem.crt
```

Одно расширение `.cer` или `.crt` не определяет формат.
Обычно достаточно доверенного корневого CA, когда сервер передаёт
промежуточный сертификат. Описание и порядок получения — в
[инструкции Сбера](https://developers.sber.ru/help/certificates/how-to).

Установка сертификатов в это изменение не входит. Для PHP/curl доверие
позднее нужно настроить внутри образа приложения: установка только
на Docker-хост не обновляет хранилище контейнера.
